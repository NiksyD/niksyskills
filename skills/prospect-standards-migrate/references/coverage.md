# Standards coverage map

This is an audit aid. Read each applicable original document in `CODE-STANDARD/` during every migration; its current text takes precedence. Classify every changed file, including new files and barrels. The requested file must be fully compliant, not merely its edited lines.

| Document | Applicable requirements to audit |
| --- | --- |
| `INDEX.md` | Master map and mandatory checklist; discover new documents. |
| `angular-v22-standalone.md` | Standalone components/directives/pipes; no `NgModule` or `standalone: false`; `OnPush` from `AGENTS.md`; local signals/computed and no local-state `BehaviorSubject`; public readonly signal inputs/outputs, protected internal template state; native `@if`/`@else`/`@for`/`@switch` with unique tracking; field `inject()`; new/substantially refactored forms use Signal Forms model/schema/`FormField`/`[formField]`/`submit()` as applicable; third-party CVA through application `SignalFormControl` compat boundary and template compilation, no package modifications; compatible legacy forms strictly typed, no untyped controls; Emulated encapsulation and no global feature overrides; `withLoading` for HTTP loading signals. |
| `typescript-class-standards.md` | Injected services first; component groups ordered services, inputs/outputs, state, constructor, lifecycle, UI handlers, API/data methods; explicit visibility, public component API, protected template members, private helpers; camelCase/accurate names, service private `_` prefix versus component injected service without `_`; signal input/output, no legacy decorators; explicit function/method/arrow return types; no `any`/`object`; split complex methods and constructor effects; interfaces/type aliases/models in owning `interfaces/` or shared `core/models`, runtime values in owning `constants/`; type-only third-party contract imports, readonly immutable contracts/collections, nearest public barrels. Favor normative prose where examples conflict. |
| `clean-code-guidelines.md` | Truthy `.length` rather than `> 0`; concise one-expression guards; early returns/reduced nesting; typed parameter object for multi-parameter domain model constructors; `const` default, `let` only when reassigned, no `var`; initialized primitives with inferred simple types; consistent primitive types. Preserve semantics and formatter compatibility. |
| `jsdoc-documentation.md` | Descriptive JSDoc on each class property; each method has matching visibility tag and meaningful `@description` covering purpose/effects/business logic; `@param` for each parameter, optional marker when needed, no type braces; `@returns` on non-void methods, none on `void`/`Promise<void>`; document exported reusable functions. Assess meaning manually. |
| `tailwind-scss-bem.md` | First component SCSS rule `:host { @apply block; }`; `@apply` for new/substantially changed visual rules; BEM semantic selectors and nesting depth at most two beyond block; only small structural utility classes in templates, visual styles in SCSS; no `::ng-deep`, `/deep/`, `>>>`, or `!important`; theme colors first, raw hex only when unavailable with required comment immediately above; no one-off Tailwind palette changes; documented scoped complex shell/layout raw-SCSS exception while retaining host/BEM/theme rules. |
| `html-template-architecture.md` | Native button or approved accessible design-system action control (`ntv-button` API), with name/keyboard/focus/disabled semantics; no clickable div/span or unapproved controls; Bootstrap `.row` directly parents `.col-*`; stable labels/messages/button/table/visual configuration in nearest `constants/<name>.constant.ts` and `constants/index.ts`, no service-owned user copy, map typed status to rendering-feature copy, shared constants only for real unrelated-feature consumers; repeated binding logic extracted to computed/variable; E2E `data-testid` bound in `component-element` kebab-case and item identifiers for lists. |
| `svg-icon-standards.md` | SVG icons through `<app-svg-icon>`; no `[innerHTML]` icons or extra sizing span; `IconService.getIconMap([...])`; supported size/host dimensions and `className`; parent SCSS `app-svg-icon.my-class`, overrides only color/margin/layout except justified header case; SVG assets in `src/assets/icons/` or `src/assets/images/`. |
| `query-builder-standards.md` | HTTP query serialization via `buildQueryParams(params)` from `@shared`; extend `BaseQueryParams` in `@shared/interfaces` with optional fields without removing existing ones; preserve API behavior. |
| `async-race-prevention.md` | Private monotonic request counter; increment on every repeatable trigger; compare after **every** await/promise resolution before side effects; increment on cancellation; ensure stale request cannot overwrite loading/error/current data. |
| `project-structure-migration.md` | Page-only component in page `components/`, multi-page feature component in feature `components/`, cross-feature component in `shared/components/`; component migration covers icon binding/map, deep selectors, SVG host selectors, encapsulation/third-party styles, host/BEM/`@apply`/specificity; build and visually verify after batches; Git inspection only. |
| `reusable-code-and-barrels.md` | Extract generally reusable pure parser/formatter/validator/normalizer to focused `shared/utils/<name>.util.ts`, JSDoc and `shared/utils/index.ts`; retain component method only for state/service/business context; nearest barrels (`@shared/components`, `@shared/utils`, `@shared/pipes`, feature), direct implementation import only if private/no barrel/documented cycle or lazy boundary; feature/domain constants ownership and service presentation separation; independent per-file and companion template/SCSS review. |

`AGENTS.md` also defines application directory boundaries, aliases, bans on `console.*` and deep relative imports, Angular `*.spec.ts` and Python `test_*.py` naming, focused tests before broad suites, exact-path checker invocation, per-file reporting, and protected-file/security/Git limits. The checker covers selected TS/HTML/SVG patterns only. It can exit successfully with an empty filtered CLI file set, so confirm intended files were accepted. Manual review remains mandatory.
